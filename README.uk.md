# ATCRiskMind: Air Traffic Controller Risk Assessment Platform

ATCRiskMind — це веб-платформа для оцінювання ризику професійної діяльності авіадиспетчерів залежно від рівня ментального здоров'я. Система оцінює показники психічного здоров'я та виснаження для надання комплексної оцінки ризиків за допомогою алгоритмів нечіткої логіки.

## Особливості

- Підтримка локалізації (англійська та українська)
- Інтерактивна візуалізація даних за допомогою ECharts
- Алгоритми оцінки ризиків на основі нечіткої логіки
- Можливість налаштувати рівні ризику
- Розрахунки та оновлення візуалізації в реальному часі

## Необхідні компоненти

- Python 3.7 або вище
- pip (інсталятор пакетів Python)

## Інструкція

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/toleksandr/ATCRiskMind.git
   cd ATCRiskMind
   ```

2. Створіть та активуйте віртуальне середовище:
   ```bash
   # Для Windows
   python -m venv env
   .\env\Scripts\activate

   # Для macOS/Linux
   python3 -m venv env
   source env/bin/activate
   ```

3. Встановіть необхідні залежності:
   ```bash
   pip install -r requirements.txt
   ```
   
4. Ініціалізуйте переклади мов:
   ```bash
   pybabel compile -d translations
   ```

## Запуск додатку

1. Запустіть Flask додаток:
   ```bash
   python app.py
   ```

2. Відкрийте веб-браузер і перейдіть за адресою:
   ```
   http://127.0.0.1:5000/
   ```

## Використання

1. Налаштуйте параметри системи (кількість авіадиспетчерів і часових періодів)
2. Використовуйте зразкові дані або згенеруйте випадкові дані для тестування
3. Перегляньте показники втоми та психічного здоров'я для кожного диспетчера
4. Перегляньте візуалізацію рівнів ризику через деревоподібні карти
5. Налаштуйте пороги рівнів ризику за допомогою повзунків

## Налаштування рівнів ризику

Додаток надає два повзунки діапазону для налаштування:
- Рівнів експертного висновку (L1-L5)
- Лінгвістичних рівнів ризику (R1-R5)

## Зберігання даних

Додаток автоматично зберігає ваші вхідні дані в локальному сховищі браузера кожні 30 секунд і коли ви закриваєте сторінку. Ці дані будуть автоматично завантажені, коли ви знову відкриєте додаток.
